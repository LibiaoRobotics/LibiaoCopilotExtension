如何获取 Webhook 地址
  1. 在企业微信里新建一个群聊（⚠️注意：不能是外部群）。
  2. 可以把多余的成员移出，群里只留自己一个人 —— 既不打扰同事，通知内容也不会外流。
  3. 打开这个群的群设置，找到「消息推送」。
  4. 点添加，选择「自定义消息推送」。
  5. 给它起个名称（比如「VS Code 通知」），并且这个界面上会给出 Webhook 地址，整条复制后填到上面即可。

如何拿到 BotID / Secret
  1. 企业微信管理后台 → 应用管理 → 智能机器人，新建一个「智能机器人」。
  2. 在机器人详情里打开「API 模式」，连接方式选「长连接」，页面会给出 BotID 与 Secret。
  3. 把两个值填到上面并保存 —— 同一个机器人只允许一条长连接，另一个窗口要用就得先断开。
  4. 先在企微里给机器人发一句话，面板会出现「未授权发送者」，点「授权此人」即可（方式一：企微 → 面板）。
  5. 也可以反过来：点面板上的「在企微里发起授权」，企微会收到一张卡片，在里面点「允许」即可（方式二：面板 → 企微）。这种方式要求对方此前已经给机器人发过消息。
