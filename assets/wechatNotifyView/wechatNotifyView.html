企微联动会在每轮对话结束时，通过企业微信群消息推送模块把本轮耗时、会话标题与所用模型发到群里，让你离开电脑也能知道任务是否跑完。
注意：创建会在当前工作区的 .github/hooks/ 目录下生成该功能所依赖的必备文件，请勿删除或改名。

如何获取 Webhook 地址
  1. 在企业微信里新建一个群聊。
  2. 把多余的成员移出，群里只留自己一个人 —— 既不打扰同事，通知内容也不会外流。
  3. 打开这个群的群设置，找到「消息推送」。
  4. 点添加，选择「自定义消息推送」。
  5. 给它起个名称（比如「VS Code 对话通知」）并确认，创建完成后这个界面上会给出 Webhook 地址，整条复制后填到上面即可。
