如何获取 Webhook 地址
  1. 在企业微信里新建一个群聊（⚠️注意：不能是外部群）。
  2. 可以把多余的成员移出，群里只留自己一个人 —— 既不打扰同事，通知内容也不会外流。
  3. 打开这个群的群设置，找到「消息推送」。
  4. 点添加，选择「自定义消息推送」。
  5. 给它起个名称（比如「VS Code 通知」），并且这个界面上会给出 Webhook 地址，整条复制后填到上面即可。
